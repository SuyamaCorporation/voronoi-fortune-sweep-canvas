# Voronoi Fortune Sweep Algorithm Canvas

## 概要
フォーチュン法の掃引線アルゴリズムでボロノイ図を構築する過程をアニメーション表示するビジュアライザー。ドロネー三角形分割（双対グラフ）の重ね合わせ表示付き。

## 機能
- Bowyer-Watson法によるドロネー三角形分割（ボロノイ図の双対として利用）
- 掃引線アニメーション（サイトをy座標順に処理する過程を可視化）
- ランダム種点生成（最大50点）
- キャンバスクリックで任意位置に種点を追加
- カラーリングされたボロノイセル（パステルカラー）
- ドロネー三角形分割オーバーレイ（白線）
- 外接円オーバーレイ（ドロネー三角形の外接円）
- セル重心表示
- 掃引線（アニメーション時）のON/OFF
- オイラーの公式 V - E + F = 2 の検証表示
- 速度スライダー・ステップ実行・リセット

## 使い方
1. 「ランダム生成」ボタンで種点を生成、またはキャンバスをクリックして追加
2. 「▶ 実行」ボタンで掃引線アニメーション開始
3. 掃引線が上から下へ移動する過程でボロノイ図が構築されます
4. 「+1イベント」で1ステップずつ確認
5. 表示オプションで「ドロネー三角形分割」や「外接円」を有効にして数学的構造を観察
6. 下部の V, E, F 値でオイラーの公式（V - E + F = 2）を確認
